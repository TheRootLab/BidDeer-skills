# Source Assets Notes

## after_sales_card.png

Synthetic after-sales service card image for demo use.

- Company: ACME Tech Solutions (fictitious)
- Hotline: 400-000-0000 (synthetic)
- Service Hours: 7x24 (synthetic)
- Email: support@example.invalid (synthetic, non-routable)

The image is a simple text-on-background rendering. It does not represent:
- A real company
- A real certificate
- A real seal
- A real signature
- A real ID card
- Any official document

The image was generated programmatically using Pillow. No real customer or vendor data was used.

The image is embedded in `../synthetic_image_proposal.pdf` on the Appendix A page.
